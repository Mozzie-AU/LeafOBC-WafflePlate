## Conventions

- `Q` = transistor die, `D` = diode die, `R`/`C` = passives, `J` = connector pin, `L` = bridging link
- Number regions in this order: top-left, middle-left, lower-left, upper-right, lower-right. Within each region, number left to right, then top to bottom.
